PROYECTO: LÍNEA DEL TIEMPO DE DISPOSITIVOS MÓVILES (1950–2028)

ARCHIVOS
- index.html   -> página principal
- styles.css   -> diseño y animaciones
- data.js      -> los 100 acontecimientos
- script.js    -> interacción, filtros, modal, sonido y recorrido automático

CÓMO ABRIR
1. Descomprime la carpeta.
2. Abre index.html con Chrome, Edge o Firefox.
3. No necesitas instalar nada.

CÓMO PRESENTAR
1. Abre la página a pantalla completa (F11).
2. Enseña la portada.
3. Presiona “Explorar la historia”.
4. Usa los botones de décadas.
5. Abre 3 o 4 acontecimientos.
6. Demuestra el buscador: escribe “5G”, “iPhone” o “IA”.
7. Activa “Recorrer” para demostrar movimiento automático.
8. Muestra que 2027 y 2028 dicen “proyección”.

SI QUIERES CAMBIAR TU NOMBRE / DATOS
Busca en index.html la parte del footer o agrega debajo del título:
<p>Nombre: TU NOMBRE</p>

PUBLICAR GRATIS EN GITHUB PAGES
1. Crea una cuenta/inicia sesión en GitHub.
2. Crea un repositorio nuevo, por ejemplo: linea-tiempo-moviles.
3. Sube los 4 archivos principales.
4. Ve a Settings > Pages.
5. En “Build and deployment”, selecciona Deploy from a branch.
6. Branch: main y carpeta /(root).
7. Guarda.
8. GitHub generará una dirección web pública para entregar al profesor.

IMPORTANTE
Los acontecimientos 2027–2028 aparecen explícitamente como proyecciones porque son fechas futuras.
Algunos hitos históricos antiguos solo están documentados públicamente por año o mes; la línea del tiempo conserva esa precisión y no inventa días.
